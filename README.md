## 👋 About

I design and ship Roblox experiences end to end, from gameplay and economy to UI, live updates and analytics. Alongside that I build native Rust desktop applications, internal dashboards and automation that runs unattended on dedicated hardware.

## 🎮 Roblox

- **+1 Cast Power**: live game, shipped with regular content updates
- **Roll a Neko**: dice-roll collection game with a custom anime-inspired world
- **Potion Factory** and **Lasso Ranch**: games in active development
- Shared asset and icon pack pipelines for production art and UI

## 🦀 Desktop applications

- **MoonwakeGear**: a single Rust app for PC lighting, cooling and AirPods control
- **MoonwakeVault**: a Rust desktop app for managing and securing multiple accounts, with encrypted local storage
- **MoonwakeLens**: YouTube trend and keyword research from public data

## 📊 Platforms and automation

- **Moonwake dashboard**: an internal control room for projects, metrics and scheduled jobs
- **Shorts Factory**: unattended pipeline that produces and publishes short-form video daily
- Runs on a dedicated home server with Cloudflare Tunnels for secure remote access
